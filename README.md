# YaCut

YaCut — веб-сервис для создания коротких ссылок и загрузки файлов на Яндекс Диск.

Проект выполнен в рамках учебной работы. Спецификация API и вспомогательные материалы были предоставлены как основа проекта. В рамках работы реализованы логика сокращения ссылок, пользовательский интерфейс, API, хранение данных и асинхронная загрузка нескольких файлов на Яндекс Диск.

## Возможности

- создание коротких ссылок для длинных URL
- использование пользовательского короткого идентификатора
- автоматическая генерация уникального короткого идентификатора длиной 6 символов
- переадресация по коротким ссылкам
- HTML-интерфейс для создания коротких ссылок
- загрузка нескольких файлов на Яндекс Диск
- асинхронная обработка загрузки файлов через `aiohttp`
- создание коротких ссылок для скачивания загруженных файлов
- публичный API для создания коротких ссылок и получения оригинальных URL
- валидация пользовательского ввода и обработка ошибок
- пользовательская страница 404

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/SV-Miki/yacut.git
cd yacut
```

Создайте виртуальное окружение:

```bash
python3 -m venv venv
```

### Linux / macOS

Активируйте виртуальное окружение:

```bash
source venv/bin/activate
```

### Windows

Для Command Prompt:

```text
venv\Scripts\activate
```

Для PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Обновите `pip` и установите зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Переменные окружения

В корневой директории проекта создайте файл `.env`:

```env
SECRET_KEY=your-secret-key
DATABASE_URI=sqlite:///db.sqlite3
DISK_TOKEN=your-yandex-disk-token
```

Используемые переменные:

| Переменная     | Описание                      |
|----------------|-------------------------------|
| `SECRET_KEY`   | Секретный ключ Flask          |
| `DATABASE_URI` | URI подключения к базе данных |
| `DISK_TOKEN`   | OAuth-токен Яндекс Диска      |

Файл `.env` не должен храниться в репозитории.

```text

```

## API

Публичный API позволяет создавать короткие ссылки и получать оригинальные URL по короткому идентификатору.

### Создание короткой ссылки

```http
POST /api/id/
```

Пример запроса:

```json
{
  "url": "https://www.python.org",
  "custom_id": "python"
}
```

Пример ответа:

```json
{
  "url": "https://www.python.org",
  "short_link": "http://127.0.0.1:5000/python"
}
```

Поле `custom_id` необязательно. Если оно не передано, сервис автоматически создаёт уникальный идентификатор длиной 6 символов.

### Получение оригинальной ссылки

```http
GET /api/id/python/
```

Пример ответа:

```json
{
  "url": "https://www.python.org"
}
```

Если короткий идентификатор не найден, API возвращает ответ со статусом `404`.

## Загрузка файлов на Яндекс Диск

Страница `/files` позволяет выбрать несколько файлов и загрузить их на Яндекс Диск.

Для загрузки используется `aiohttp`. Несколько файлов обрабатываются асинхронно, после чего для полученной ссылки на скачивание каждого файла создаётся отдельная короткая ссылка YaCut.

Для работы этой функции необходимо указать действующий OAuth-токен Яндекс Диска в переменной окружения:

```env
DISK_TOKEN=your-yandex-disk-token
```

## OpenAPI и Postman

Описание публичного API находится в файле:

```text
openapi.yml
```

В директории:

```text
postman_collection/
```

находятся Postman-коллекция и вспомогательные материалы для проверки API.

Перед запуском коллекции выполните скрипт:

```bash
cd postman_collection
bash set_up_data.sh
```

Он очищает существующие записи и создаёт данные, необходимые для работы коллекции.
